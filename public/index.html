Checking...

            

            

            

              Download certificate
              
            

            

              The downloaded certificate can be installed as trusted on a computer (Windows:
              right-click it → Install Certificate → Trusted Root Certification
              Authorities), which removes the browser warning on that computer.
            


            

              
Use your own certificate

              

                If you have a proper certificate for this server's name, upload it here and browsers
                stop showing a warning. You need two files from whoever issued it (your IT team or a
                certificate provider): the certificate (.pem, .crt or .cer) and its private key
                (.key or .pem). No restart needed. Use Check files first to see
                what is in them.
              

              

                
                
              

              

                
                
              

              

                
                
              

              

                
                
              

              

            

          


          

            


            
Back up everything

            

              One file with all of the app's saved information: user accounts and access groups, the
              screens and sources list (with its saved earlier versions), branding, settings and the
              activity log.
            

            

              Download full backup (.zip)
            

            

              Keep the file private. It contains everyone's accounts, including their password
              hashes.
            

            
Not included

            

              The HTTPS certificate and its key. The app makes a new self-signed certificate, or you
              upload your own again in the Security tab.
            

            
Restoring

            

              1. Stop the app.
2. Unzip the file into the app's data folder (the
              data folder next to the app, unless it was moved), replacing the files
              with the same names.
3. Start the app. People sign in with the same passwords as
              when the backup was made.
The same steps are written in
              RESTORE.txt inside the zip.
